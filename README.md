## 🚀 About Me

I am an AI security researcher and cybersecurity data scientist with over 11 years of experience building and analysing AI, security, and data-driven systems.

My current work focuses on **AI Security, Agentic AI, Adversarial Machine Learning, LLM Security, Model Context Protocol (MCP), AI Red Teaming, and secure AI architectures**.

I also create hands-on cybersecurity training, research prototypes, and technical content focused on understanding how AI systems can be attacked, evaluated, and defended.

## ⭐ Featured Projects

### 🐉 AgentBreak
Research project focused on **agentic AI attack chains**, including prompt injection, tool abuse, context manipulation, memory poisoning, and trust-boundary failures.

### 🛡️ MCP-SHIELD
Defensive research project focused on securing **Model Context Protocol ecosystems**, tool permissions, capability boundaries, validation, and runtime controls.

### 🌌 Orion
Adversarial AI experimentation framework for evaluating and defending **traditional machine learning and generative AI systems**.

### 🔥 GhostfaceFuzzer
Adversarial fuzzing toolkit for LLMs and image classifiers, including jailbreak generation, perturbation pipelines, evaluation metrics, and red-teaming workflows.
